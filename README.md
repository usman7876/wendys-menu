# Wendy's Menu with Prices (USA)

An independent, fan-run reference website for the USA Wendy's menu: prices and calories, clearly sourced and dated. It takes no orders and is **not** the official Wendy's site.

## The domain lives in exactly ONE place

The site URL is set only in `astro.config.mjs` (`site: 'https://wendys-menu-eight.vercel.app'`). Everything else is derived from it — canonical tags, Open Graph / Twitter URLs, the share image URL, all JSON-LD URLs, the sitemap, and `robots.txt` (generated by `src/pages/robots.txt.ts` from the same setting). **To connect a custom domain later, change that one line in `astro.config.mjs` and rebuild.** Do not edit URLs per page; there are none hard-coded.

## What is in this folder

A proper Astro website (static, no server, no database), built from the file tree Muhammad chose:

- `src/data/menu.json` — the **one verified data list**: 150 items, with prices, calories, protein, fat, carbs, sodium and an official source URL per item. A value that was not verified is `null` and the page renders it as “Not verified yet”. Calorie ranges (`calories_low` / `calories_high`) are used where Wendy's shows a range, not one figure (Coca-Cola Freestyle, national-only drinks). A `note` on an item flags a disagreement on Wendy's own pages. Price ranges are supported too (`price_low` / `price_high` / `price_median`, all null for now — one restaurant only). Since Phase 1 the file also holds the `deals`, `comparison` and `hours` sections that used to live in `src/data/stage5.json` (deleted 22 Nov 2026); nothing was renumbered in the merge.
- `src/pages/` — 20 pages: homepage (landing page only), full menu, breakfast, 5 category pages (burgers, chicken, sides, desserts, drinks), nutrition, calories, deals, hours, Wendy's vs McDonald's, how we source prices, about, editorial team, contact, privacy, cookies, terms. Plus `robots.txt.ts`, which generates robots.txt from the site setting.
- `src/components/` — TopNotice, Header (mega-menu + mobile hamburger), Footer, PopularTable, SearchBox, CategoryChips, ItemCard, Faq, Sources, AdSlot, Breadcrumbs, RelatedLinks, CategoryPage, TiltScript, plus DealsBoard, ComparisonBoard and HoursBoard for Stage 5.
- `src/layouts/BaseLayout.astro` — every page's head: canonical, Open Graph / Twitter share tags, theme-color, favicon + apple-touch-icon, and JSON-LD (Organization, WebSite, BreadcrumbList, FAQPage, ItemList — only facts visible on that page). `src/utils/faqData.js` builds the FAQ list once, so the visible FAQs and the FAQPage data can never disagree.
- `src/styles/global.css`, `src/utils/menuStats.js` (includes `itemSlug()` for card ids and `popularItems()` for the homepage's six).
- `public/favicon.svg`, `public/apple-touch-icon.png`, `public/fonts/` (self-hosted Fraunces + Inter), `public/images/` — 60 original AI-generated natural food photos as **WebP** (converted from JPG in Phase 3, ~70% smaller) plus `og-image.jpg` (1200×630 share image, JPG — social platforms handle JPG best), each captioned on the page “Original AI-generated image — not an official photo”. No Wendy's logo and no official food photos. Convert again with `node scripts/convert-images.mjs` if photos are replaced.

## The data rules (do not break them)

- Prices are from **one restaurant only**: Wendy's, 799 S. High Street, Columbus, OH 43206, Carryout, checked **22 Nov 2026** on order.wendys.com. Every price on the site carries that basis label. Wendy's publishes no national price list; prices vary by location.
- Breakfast hours are from Wendy's official breakfast FAQ (wendys.com): most start **6:30 AM**, latest end **10:30 AM**, delivery begins **8:00 AM**.
- Breakfast **calories** are from Wendy's official item pages. Breakfast **prices are not verified** (the check was after breakfast ended) — they render as “Not verified yet”, never guessed.
- The **Oatmeal Bar was not found** on the official site (404) — it is not a menu item, only mentioned in the sourcing note. The **Frosty-ccino was not found** at the Columbus restaurant either (not in the Frosty or Coffee categories) — it is not a menu item; a morning re-check is needed.
- No third-party price site and no UK nutrition PDF was used. Only wendys.com, order.wendys.com, locations.wendys.com (hours) and mcdonalds.com (comparison only).
- Where Wendy's own pages disagree, both figures are shown and flagged, never reconciled: Deals calories, Family Chili (1,370 vs 530 Cal), the nuggets listed as sides, the Cookie Bundle (1,670 shown vs 5 × 330 = 1,650), and the breakfast end (11:00 AM today at this restaurant vs 10:30 AM latest nationally).
- The 3 “Advertisement” boxes are empty reserved spaces. There is **no ad code** on the site. Ads stay off until Muhammad confirms Google AdSense approval.

## Run it locally

```bash
cd wendys-menu
npm install
npm run dev     # local preview, usually http://localhost:4321
npm run build   # builds into dist/
npm run preview # serves the production build
```
