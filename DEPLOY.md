# Deploying the Wendy's Menu site

**Status: NOT deployed yet.** This is deployable code in `~/workspace/wendys-menu/`, not a live site.

## What it is

A static Astro site. `npm run build` outputs plain HTML/CSS/JS into `dist/`. There is no server, no database, and no build-time secret to configure.

## Option A — Vercel (recommended, free to start)

1. Push this folder to a new, empty GitHub repo.
2. In Vercel: Add New Project → Import that repo. The framework is auto-detected as Astro.
3. Build command: `npm run build`. Output directory: `dist`.
4. Deploy. The site goes live at a `*.vercel.app` address.
5. (Optional, later) Add a custom domain in Vercel → Settings → Domains, and point the DNS records Vercel shows you at your registrar. HTTPS is automatic.

## Option B — Netlify

1. Push the folder to a GitHub repo.
2. In Netlify: Add new site → Import from Git. Build command: `npm run build`. Publish directory: `dist`.
3. Deploy. The site goes live at a `*.netlify.app` address; add a custom domain later in Site settings → Domain management.

## Option C — any static host

Run `npm run build`, then upload the contents of `dist/` to the host.
